# Componentes Comunes

Esta carpeta contiene componentes reutilizables que pueden ser utilizados en diferentes partes de la aplicación. A continuación, se describen los componentes disponibles:

## Avatar
Componente para mostrar un avatar de usuario.

- **Props:**
  - `src` (string): URL de la imagen del avatar.
  - `alt` (string): Texto alternativo para la imagen.

## Header
Encabezado reutilizable para diferentes vistas.

- **Props:**
  - `title` (string): Título a mostrar en el encabezado.

## Notification
Componente para mostrar notificaciones.

- **Props:**
  - `message` (string): Mensaje de la notificación.
  - `type` (string): Tipo de notificación (`success`, `error`, etc.).
